## description
Data file formats vs table formats explained: Parquet is a file format, Iceberg is not. #shorts
10 formats in one list: CSV, JSON, JSON Lines, Avro, Parquet, ORC, Arrow, Delta Lake, Iceberg and Hudi.

File format: how bytes sit in a file. Table format: which files form the table, as metadata over data files such as Parquet. Files store data. Tables track files.
