audio_name: QueryUnstuck – AI/LLM terms

15 AI/LLM terms data engineers must know.

Tokens, embeddings, RAG and more, grouped in three cards:

Talking to the model
1. Token: a chunk of text the model reads
2. Context window: max tokens per request, output included
3. Prompt: the instructions and data you send
4. Temperature: controls randomness; 0 can still vary
5. Tool calling: model emits a call; app or API runs it

Finding the right data
6. Chunking: split docs into retrievable pieces
7. Embedding: a vector of numbers for meaning
8. Cosine similarity: how closely two vectors align
9. Vector index: structure for fast similarity search
10. ANN search: approximate; trades recall for speed

Making answers reliable
11. RAG: retrieve relevant data, then generate
12. Fine-tuning: further train a model on your own data
13. Hallucination: output that is false or unsupported
14. Evals: repeatable tests of output quality
15. Guardrails: checks on inputs and outputs

RAG answers depend on what you retrieve.
